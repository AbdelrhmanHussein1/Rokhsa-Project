# Rokhsa Project
ROKHSA — Driver Licensing Workflow Governance System (Graduation Project) | C# | .NET | SQL Server | ADO.NET | 3-Tier Architecture • Enterprise desktop app managing the full driver licensing lifecycle with a custom Application State Machine. • Enforces a non-reversible test sequence (Vision → Theory → Practical), blocking all manual procedural bypasses. • Features dynamic fee calculation, automated renewal/replacement, and a granular Detain & Release (Lock/Unlock) sub-system. • Strict 3-Tier Architecture (Presentation/BLL/DAL) with national-ID uniqueness constraints and full data integrity.
